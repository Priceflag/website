Globe + revenue counter

Standalone prototype for sections/pf-globe.js. The module builds every node it needs inside the mount, injects its own <style> once and returns a cleanup function. Scroll down: the counter starts on intersection and eases from $0 to exactly $1,342 over two seconds. After it lands it creeps by a single dollar every ten to twenty seconds — and every one of those ticks lights a neon point on the globe.

Layout is decided in JS from the section's own width over the viewport height, not from a media query: wide-and-short puts the globe beside the number, tall-and-narrow stacks them. Resize the window or rotate the device and it re-lays-out live, with no reload. The width buttons below narrow the mount; rotate the window itself to exercise the short-viewport path.

The readout below is measured, not eyeballed: it samples the real backing store with getImageData and counts pixels that are not the page background. This page can run with document.hidden === true, which starves requestAnimationFrame and IntersectionObserver alike, so a screenshot proves nothing and a lit-pixel count proves everything.
